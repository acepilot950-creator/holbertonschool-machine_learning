In this task, a function is implemented to perform horizontal flipping of images using TensorFlow operations.

---

## Learning Objectives

By completing this project, you should be able to:

- Understand the concept of data augmentation
- Apply basic image transformations using TensorFlow
- Work with 3D tensors representing images
- Use TensorFlow's built-in image processing functions

---

## Requirements

- Ubuntu 20.04 LTS
- Python 3.9
- TensorFlow 2.15
- tensorflow-datasets 4.9.2
