# Clustering

This project focuses on unsupervised machine learning algorithms used to group similar data points into clusters.

The project covers the implementation of clustering algorithms using Python and NumPy, including centroid initialization and K-means clustering.

## Learning Objectives

By the end of this project, I should be able to explain:

- What clustering is
- The difference between supervised and unsupervised learning
- How K-means clustering works
- How cluster centroids are initialized
- How data points are assigned to clusters
- How cluster centroids are updated
- How to determine whether K-means has converged
- The limitations of K-means clustering
- How to evaluate clustering results
