# Dimensionality Reduction

This project covers the fundamentals of dimensionality reduction in Machine Learning using NumPy.

## Topics

- Principal Component Analysis (PCA)
- Singular Value Decomposition (SVD)
- Eigenvalues and Eigenvectors
- Variance preservation
- Data compression
- Feature extraction

## Requirements

- Ubuntu 20.04 LTS
- Python 3.9
- NumPy 1.25.2
- pycodestyle 2.11.1
