# Classification Using Neural Networks

This directory contains implementations of basic concepts of **binary classification using neural networks**.

The goal of these exercises is to understand how neural networks work **from scratch** using **NumPy**, without relying on high-level machine learning frameworks.

## Topics Covered

- Artificial neuron initialization
- Weight and bias representation
- Forward propagation
- Sigmoid activation function
- Binary classification
- Cost function (log loss)
- Gradient descent optimization
