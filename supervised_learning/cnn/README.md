Convolutional Neural Networks (CNN)

This project focuses on implementing the fundamental components of Convolutional Neural Networks (CNNs) using NumPy. The goal is to understand how convolutional layers work internally by implementing the forward propagation step manually without relying on high-level deep learning libraries.

The exercises in this directory explore the mathematical operations behind convolution, including kernel application, stride movement, padding strategies, and activation functions.

Learning Objectives

By completing this project, you should understand:

What a convolutional layer is
How kernels (filters) extract features from images
The difference between valid and same padding
How stride affects the output size
How convolution operations are implemented using NumPy
How activation functions are applied to convolution outputs
How CNNs create feature maps
Technologies Used

The implementations in this project use:

Python 3.9
NumPy 1.25.2
Ubuntu 20.04 LTS

No deep learning frameworks (such as TensorFlow or PyTorch) are used for the core implementations in order to better understand the internal mechanics of CNN layers.
