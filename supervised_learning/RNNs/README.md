# RNNs

## Description

This project introduces Recurrent Neural Networks (RNNs) and their use
with sequential data.

An RNN processes a sequence one element at a time while maintaining a
hidden state. The hidden state allows information from previous time steps
to influence the current computation.

The project covers the implementation of recurrent neural network cells
and forward propagation through sequential data.

## Learning Objectives

By the end of this project, I should be able to explain:

- What a Recurrent Neural Network is
- How an RNN processes sequential data
- What a hidden state represents
- How a simple RNN cell works
- How forward propagation is performed in an RNN
- The difference between basic, deep, and bidirectional RNNs
- How softmax is used to generate output probabilities
- How RNN weights and biases are initialized
