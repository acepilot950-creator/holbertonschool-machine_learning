# Optimization

This directory contains solutions for optimization tasks used in machine learning.

The goal of this project is to implement fundamental techniques that help improve the training of machine learning models, such as feature normalization and optimization methods.


## Requirements

- Ubuntu 20.04 LTS
- Python 3.9
- NumPy 1.25.2
- TensorFlow 2.15
- pycodestyle 2.11.1

## Description

Feature normalization is an important preprocessing step in machine learning.  
It helps gradient-based optimization algorithms converge faster and improves model stability.
