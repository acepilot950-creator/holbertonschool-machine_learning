# Attention

This project explores attention mechanisms and sequence-to-sequence models used in Natural Language Processing and machine translation.

The project begins with an RNN-based encoder and decoder architecture and introduces attention as a way for a decoder to focus on the most relevant encoder outputs when generating each word of an output sequence.

## Learning Objectives

By the end of this project, I should be able to explain:

- What the attention mechanism is
- How an encoder-decoder architecture works
- What a hidden state represents in a recurrent neural network
- How word embeddings are used in NLP models
- How GRU layers process sequential data
- The difference between encoder outputs and the final hidden state
- How attention improves sequence-to-sequence models
- What transformers are
- How self-attention works
- What BERT is and how it can be fine-tuned for NLP tasks
