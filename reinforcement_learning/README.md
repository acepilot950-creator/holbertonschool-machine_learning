# Reinforcement Learning

This repository contains projects and exercises focused on reinforcement
learning concepts and algorithms.

## Description

Reinforcement learning is a branch of machine learning in which an agent
learns how to make decisions by interacting with an environment. The agent
performs actions, observes new states, receives rewards, and improves its
behavior over time in order to maximize cumulative reward.

The projects in this directory explore fundamental reinforcement learning
concepts, including:

- Agents and environments
- States and actions
- Rewards
- Policies
- Value functions
- Exploration and exploitation
- Markov Decision Processes
- Q-learning
- Epsilon-greedy strategies

## Environment

All projects are written and tested with:

- Ubuntu 20.04 LTS
- Python 3.9
- NumPy 1.25.2
- Gymnasium 0.29.1
- pycodestyle 2.11.1

## Requirements

Python files:

- Start with `#!/usr/bin/env python3`
- End with a new line
- Follow `pycodestyle`
- Contain documentation for modules, classes, and functions
- Are executable
