# Bayesian Probability

## Overview

This project introduces the fundamental concepts of **Bayesian probability** and **Bayes' theorem**, which are widely used in statistics, machine learning, and data science.

Bayesian inference allows us to update our beliefs about a probability as new data becomes available.

In this project, we work with binomial likelihoods and Bayesian inference to estimate the probability of an event given observed data.

For example, we analyze the probability that a patient will develop severe side effects from a drug using clinical trial results.

---

## Bayes' Theorem

Bayes' rule describes how to update probabilities when new evidence is observed:

P(A | B) = P(B | A) * P(A) / P(B)


Where:

| Term | Meaning |
|-----|------|
| **P(A | B)** | Posterior probability |
| **P(B | A)** | Likelihood |
| **P(A)** | Prior probability |
| **P(B)** | Marginal probability |
