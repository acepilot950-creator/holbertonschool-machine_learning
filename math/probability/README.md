# Probability

## Overview

This project introduces the fundamental concepts of **probability theory** used in **data science and machine learning**.  
The goal of this project is to understand how different probability distributions work and how they can be implemented using Python.

In this directory, we implement probability distributions from scratch, focusing on their mathematical properties and how they are used to model real-world events.

The implementations are written in **Python 3** and follow strict coding standards.

---

## Learning Objectives

After completing this project, you should understand:

- What probability distributions are
- How to model random events using probability
- The difference between discrete and continuous distributions
- How to implement statistical models in Python
- How distributions like **Poisson**, **Binomial**, **Normal**, and **Exponential** are used in machine learning
