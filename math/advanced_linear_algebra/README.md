# Advanced Linear Algebra

This directory contains implementations of advanced linear algebra operations using pure Python.

The goal of this project is to build a deeper understanding of matrix theory by implementing core mathematical operations without relying on external libraries such as NumPy.

---

## 📚 Concepts Covered

- Determinant (recursive Laplace expansion)
- Minors
- Cofactors
- Adjugate matrices
- Matrix inverse
- Matrix validation and error handling
